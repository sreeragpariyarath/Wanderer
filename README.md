# Wanderer — Next.js

```bash
npm install
npm run dev
```

Open http://localhost:3000.

- `components/Wanderer.jsx` — client component (markup + controls)
- `lib/WandererEngine.js` — canvas engine (terrain, trees, river, village, launch, loading screen)
- `app/globals.css` — Classical design tokens

Controls: A/D or ←/→ to walk, Shift to run, Space to open a card.
